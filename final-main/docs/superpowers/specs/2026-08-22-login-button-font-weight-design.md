# 登录按钮文字字重优化设计

## 目标

取消登录窗口中“登录”“申请注册”“返回登录”三个按钮文案的加粗效果，使其使用常规字重。

## 方案

- 主责文件：`apps/main-platform/app/styles/window-1-login.css`
- 协同文件：无
- 在现有 `.svg-submit` 公共按钮规则中，将 `font-weight` 从 `600` 调整为 `400`。
- 不修改按钮尺寸、颜色、边框、交互状态、动画或登录/注册逻辑。

## 扩展性审查

三个目标按钮共用 `.svg-submit`，统一调整公共规则可以覆盖登录和注册分支，避免在组件中为不同文案增加重复样式。后续若新增同类登录窗口按钮，将自动继承常规字重；若某个按钮需要独立强调，可通过更具体的局部选择器单独覆盖。

## 验证

- 检查 CSS 改动仅涉及 `.svg-submit` 的字重声明。
- 运行前端 TypeScript 类型检查，确认样式调整未影响组件代码。
