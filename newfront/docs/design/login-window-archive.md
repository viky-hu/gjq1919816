# 登录窗口设计归档

## 归档目的

2026-08-21 起，首页不再挂载登录窗口，改为纯净的深色 SVG 画布。本文件保留原页面的内容、视觉组织和实现方法，供后续恢复或再设计时参考。源代码仍保留在 `apps/main-platform/app/login-window-demo.tsx` 与 `apps/main-platform/app/windows/**`。

## 内容与窗口编排

- 顶层入口为 `LoginWindowDemo`，管理 `login`、`macro`、`database`、`main` 四种窗口状态。
- 登录成功后进入宏观窗口；可在宏观、主对话、数据库窗口间切换；返回登录会重置运行时状态并重新触发首屏动效。
- 登录首屏的信息层级依次为品牌 `S-Graph`、系统标题“密态智图——联邦知识图谱协同检索引擎”、三行能力说明、`SECRET / SECURE / SMART` 微文案，以及“点击登录”行动入口。
- 演示身份由本地认证适配器提供：`admin / 311311` 为中心节点管理员，`user / 123456` 为边缘节点用户。

## SVG 与布局方法

- 首屏主体使用满视口 SVG 覆盖层，文本、顶部辅助线、行动入口和悬浮色带均由 SVG 元素构成。
- 页面中的命中按钮独立于可视 SVG 文本，使用脚本读取 `getBBox()` 后同步为可点击区域，避免视觉文案与交互区域错位。
- 布局坐标由 `window.innerWidth` 与 `window.innerHeight` 在运行时计算；品牌、标题、辅助文案、行动入口以相对视口比例和 clamp 范围定位。
- SVG 必须显式设置 `viewBox="0 0 viewportWidth viewportHeight"` 并在 resize 时同步，保证 CSS 视口尺寸与 SVG 内部坐标系一致，避免内容被挤出视口。
- 色带通过 `clipPath` 复制一组反色文本，色带宽度与中心点由动画状态控制，实现文本进入色带时的反色效果。

## 视觉语言与 CSS

- 登录窗口的基底色为偏暖白，主强调色为蓝紫；主标题使用近黑色，说明文字使用低对比灰色，色带及打开的表单面板使用饱和蓝紫。
- 字体以“DingTalk JinBuTi”为主，回退到中文系统字体；品牌、标题、说明文字和微文案分别使用独立字号、字重与字距，形成机械化信息层级。
- 样式集中在 `app/styles/window-1-login.css`，主要使用 CSS 变量管理表面、强调色、文字、辅助线及字体族；响应式断点位于窄屏场景。
- 登录表单处于展开的竖向色带内，通过透明、位移和可点击状态切换展示；表单本身保留轻量下划线字段与方括号式操作按钮。

## GSAP 动效方法

- 动效由 `@gsap/react` 的 `useGSAP` 管理，所有 DOM 引用局部保存并在清理函数中移除事件与杀死 tween。
- 空闲状态中，指针位置驱动色带的中心点与宽度；离开页面或静止后回缩为设备像素对齐的细线。
- 点击行动入口后，GSAP timeline 按顺序显示遮罩、展开色带、淡入并上移表单；关闭时反向收起表单、遮罩和色带。
- 所有几何值使用设备像素对齐，减少细线和 SVG 边界在高 DPI 下的模糊；`prefers-reduced-motion` 会将时间线压缩为即时状态切换。

## 复用建议

- 恢复该设计时，优先恢复 `LoginWindowDemo` 的窗口编排与 `LoginIntroWindow` 的 SVG 层，不要将坐标驱动动画迁移为静态 Tailwind 布局。
- 后续新窗口应维持既有分层：窗口 UI 在 `app/windows/**`，跨窗口逻辑进入 `app/lib/**` 或共享组件，浏览器后端调用继续经过 `app/api/**`。
- 如需重新启用白色登录视觉，恢复 `globals.css` 的全局色彩前，应确认其不会覆盖新首页的 `#353330` SVG 画布。
