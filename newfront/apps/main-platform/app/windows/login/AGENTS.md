# AGENTS.md（Window 1：登录）

## 作用域
本文件作用于 `apps/main-platform/app/windows/login` 目录树。

## 模块职责
- `LoginIntroWindow.tsx`：登录前引导与阶段动画。
- `LoginForm.tsx`：登录/注册表单交互。
- `utils.ts`：登录窗口工具函数。

## 开发规则
1. 阶段切换逻辑（intro -> form）需集中管理，避免状态分散。
2. 注册/登录分支复用同一表单骨架，避免重复实现。
3. 动画层不可影响表单可访问性与交互可用性。
4. 第一窗口属于项目的品牌门面，默认沿用当前“画布思维”方案：以 `SVG + GSAP` 为核心，用统一坐标系驱动线条、面板、文案和 Logo 的关系，不要轻易改成常规卡片式登录页。
5. 当前登录区的成熟语言包括：蓝白主色、几何线框、阶段化切换、`DingTalk JinBuTi` 主字体、`Michroma` 点缀字体、低存在感的 Beams 氛围背景；新方案应在这套语言内部迭代，而不是另起一套风格。
6. 对登录页的改版，优先复用 `shared/coords.ts`、`shared/animation.ts`、`utils.ts` 中现有坐标和时间轴组织方式；若必须调整，也应保持“坐标驱动 + 动画与业务解耦”的结构。

## 扩展性审查重点
- 新增认证方式（如验证码/SSO）是否可插拔；
- 文案与状态是否可配置，而非写死在多处；
- 动画与业务逻辑是否保持解耦。
